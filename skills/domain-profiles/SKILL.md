# Domain Profiles Skill

## Goal

Avoid forcing every project into a software-only workflow.

## Software

Look for:

- manifest files
- tests
- build commands
- CI
- deployment paths

Validate with tests, lint, typecheck, build.

## Knowledge base

Look for:

- index pages
- taxonomy
- citations
- source notes
- duplicate topics

Validate with link/citation/taxonomy checks when available.

## Writing system

Look for:

- voice guide
- audience
- canon
- drafts
- publication flow

Validate with continuity and style checks.

## Creative generation / ComfyUI

Look for:

- workflow JSON
- model paths
- LoRA/preset lists
- prompt templates
- outputs

Do not edit workflow JSON or overwrite outputs without explicit approval.

## AI workflow

Look for:

- prompts
- tools
- MCP servers
- evals
- schemas
- sandbox boundaries

Validate with evals, schema checks, and prompt injection review.
