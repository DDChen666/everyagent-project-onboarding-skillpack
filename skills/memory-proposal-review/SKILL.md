# Memory Proposal Review Skill

## Goal

Prevent private, stale, or low-evidence observations from becoming canonical project truth.

## Review questions

For each proposal:

1. Is the observation durable?
2. Is the evidence specific?
3. Is the confidence justified?
4. Does it conflict with existing canon?
5. Is the suggested destination correct?
6. Is validation possible?
7. Is the proposal tool-specific or project-general?

## Outcomes

- accept into canon
- accept with modification
- keep as proposal pending more evidence
- reject as stale or unsupported
- split into multiple proposals

## Rule

Do not accept a memory proposal merely because an agent wrote it confidently.
