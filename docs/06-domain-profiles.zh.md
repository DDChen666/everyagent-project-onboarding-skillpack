# 專案類型 Profile

## 程式專案

重點是測試、型別、lint、build、部署、API 邊界。

## 知識庫

重點是索引、分類、引用、過時資訊、重複內容、術語表。

## 寫作系統

重點是 voice、audience、style、continuity、world canon、出版流程。

## ComfyUI / 創作生成系統

重點是 workflow JSON、模型、LoRA、prompt template、negative prompt、seed、preset、輸出目錄。

workflow JSON、模型路徑、角色設定、風格 preset 都是高風險區，不應默默修改。

## AI workflow

重點是 prompts、evals、MCP、tool permissions、schema、sandbox、prompt injection 邊界。
